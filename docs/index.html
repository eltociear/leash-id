Who is behind this agent?

Leash ID ties AI agents to a KYC-verified human (an ME ID) and limits what they can spend, enforced by a contract on ME Hub. Paste an agent address to see who answers for it and whether it can pay right now. Read live from the chain, no wallet needed.

Every number on this page comes from a smart query to the contract, which reads ME IDs from ME Hub's DID module (/metaearth.did.Query/Did) at query time. A leash only covers agents registered with this contract. Source: github.com/eltociear/leash-id
